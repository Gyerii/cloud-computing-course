# Cloud Concepts Reflection

## Cloud Services I Use

In my daily life, I regularly use several cloud-based services, including
**Google Drive**, **Netflix**, **GCash**, and **Canva**. These platforms
have become essential tools for storage, entertainment, financial
transactions, and creative work.

## Identifying the Models

**Google Drive** is a Software as a Service (SaaS) application running on
a Public cloud deployment. I classify it this way because I simply use
the software through my browser without managing any infrastructure, and
Google provides it to the general public through shared servers.

**Netflix** is also SaaS on a Public cloud. I only interact with the
streaming application itself, while Netflix manages all the backend
infrastructure, servers, and content delivery networks behind the scenes.

**GCash** is SaaS as well, but I consider it closer to a Hybrid cloud
deployment. Since it handles sensitive financial data, it likely combines
private cloud infrastructure for secure transactions with public cloud
components for general app functionality, balancing accessibility with
security compliance.

**Canva** is another SaaS application on a Public cloud, since anyone can
sign up and use its design tools instantly without installing anything or
managing servers.

## Git & GitHub for Cloud Projects

Version control is critical when working with cloud infrastructure
because cloud projects often involve multiple files, configurations, and
contributors working simultaneously. Without version control, changes
could easily overwrite each other, causing lost work or broken
deployments.

GitHub helps teams collaborate by allowing multiple people to work on
different branches at the same time without conflicts. It tracks every
change made to a project, so if an error is introduced, developers can
easily identify what changed and roll back to a previous working version.
This is especially important in cloud environments, where mistakes in
configuration files can affect live systems used by real users. GitHub
also provides a clear history of who made which changes and when, making
accountability and debugging much easier for teams managing cloud
resources together.
